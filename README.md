 Featured Projects

 1. NIRIK — Message Intelligence

NIRIK is an SMS spam detection project developed using Python and machine learning techniques. It analyzes text messages and classifies them as spam or legitimate messages.

Technologies: Python, NLTK, Pandas, Scikit-learn, TF-IDF, Logistic Regression, Streamlit.

Key Features:

* Text preprocessing and cleaning.
* Text feature extraction using TF-IDF.
* Machine learning-based message classification.
* Interactive user interface built with Streamlit.
* Model evaluation using classification metrics and a confusion matrix.

2. Vistara AI Chatbot

Vistara is an AI chatbot project included in my development portfolio. It represents my interest in building interactive applications and exploring AI-powered user experiences.

Focus: Chatbot development, frontend development, and interactive user experiences.
